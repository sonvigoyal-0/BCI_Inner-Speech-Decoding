## Brain and Neuroscience for BCI

![Brain Digram](<brain digram.png>)


# 1. Motor Cortex:- (Motor Imagery)
- Part of brain which control movement
- Example:- if left hand moves , mortor cortex gets active generate signals which are detected by EEG and computer shows left hand 

# 2. Sensorimotor Cortex :-
- Combination of movement + touch 
- when we imagine to move our left hand , then this part gets active 

# 3. Visual cortex :-
-  Processes all visuals seen by the eyes
- Example :- we look for 15hz flashing light , then VC will get active and generate signals which will be recorded by EEG and result will be shown on computer using BCI

# 4. Neurons :-
- Brain cells
- these recieve info and process them and send electrical signals which are recorded using EEG

# 5. Synapse :-
- The gap between two neurons 
- The signal moves between neurons using chemical as **Neurotransmitters** (which helps in communication between neurons)
